# 🐍 C to Python

Repositório dedicado aos meus estudos e práticas em **Python**, explorando a transição dos conceitos de lógica de programação aprendidos anteriormente em **C** para a sintaxe e os recursos do Python.

O objetivo é documentar minha evolução na linguagem por meio da resolução de exercícios, exemplos práticos e implementação dos conceitos estudados ao longo da disciplina.

---

## 📚 Sobre o repositório

Após construir uma base de **Lógica de Programação utilizando C**, comecei a aprofundar meus conhecimentos em Python durante a disciplina de **Machine Learning**.

Este repositório acompanha esse processo, mostrando como conceitos já conhecidos de programação podem ser aplicados utilizando uma linguagem com características e sintaxe diferentes.

Os conteúdos estão organizados por tópicos, permitindo acompanhar progressivamente os conceitos estudados e as respectivas atividades.

---

## 🎯 Objetivos

- Praticar os fundamentos da linguagem Python;
- Reforçar conceitos de lógica de programação;
- Comparar, quando relevante, diferenças entre C e Python;
- Resolver e documentar exercícios propostos durante os estudos;
- Desenvolver boas práticas de organização de código;
- Registrar minha evolução no aprendizado da linguagem.

---

## 🗂️ Organização do repositório

Os conteúdos deste repositório são organizados por **tópicos de estudo**, seguindo a progressão dos assuntos abordados durante as aulas e atividades.

Cada tópico reúne os exercícios e códigos correspondentes ao conteúdo estudado, facilitando a organização e o acompanhamento da minha evolução em Python.

A estrutura será atualizada progressivamente conforme novos conteúdos forem abordados.

---

## 💻 Tecnologias

As principais tecnologias utilizadas neste repositório são:

- 🐍 **Python** — linguagem principal utilizada na resolução dos exercícios e na prática dos conceitos estudados.
- 🔵 **C** — linguagem utilizada anteriormente no aprendizado de lógica de programação e utilizada como referência para compreender as diferenças entre as duas linguagens.
- 🔧 **Git** — utilizado para versionamento dos códigos e acompanhamento das alterações realizadas no repositório.
- 🐙 **GitHub** — utilizado para armazenar, organizar e documentar os exercícios e a evolução dos estudos.
